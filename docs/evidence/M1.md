Limits of the scale number: synthetic code is regular and simple, and JCL was not yet parsed at this point. Re-measured on the final build with JCL parsing in: 1,681,618 lines, 1,892 members, 0 failed, 80 s on 8 threads, 1.04 GB peak process memory (`/usr/bin/time -l`, database excluded), with other work running on the machine.

Commands: `./mvnw -pl discovery -am verify`; `java -jar cli/target/toolkit.jar synth --out DIR --lines 1000000`; `java -jar cli/target/toolkit.jar discover --root DIR --threads 8`.

Defects found by these runs and fixed: self-deadlock on graph_node rows between a member's transaction and node upserts; copy_use deadlock between copybook and program writers; multi-line EXEC SQL swallowed by the INCLUDE scanner; blank-heavy EBCDIC read as ASCII; `USING` lines classified as Assembler.
