# M8 evidence

`ui/e2e/m8.spec.ts`, 12 Playwright tests in real Chromium, against the real API, on real CardDemo discovery with replayed real-model knowledge. Run with `cd ui && TOOLKIT_CHECKOUT=<repo> npm run e2e`.

| Acceptance | Result |
|---|---|
| An SME approves a rule and retrieval ranks it higher | CBACT04C-R1 for "transaction": rank 10 before approval, 1 after |
| A lead confirms a link and approves a deviation | Passes; the gap report follows |
| The tracker reflects `migration_status` | Passes |

The search in the first row changed from "interest" to "transaction" when ranking improved, since the rule had become first for "interest" before any approval, which would prove nothing.

Also tested: role-based navigation, wrong password, OpenAPI copy matching the server, a long source staying virtual, inventory, setup wizard and admin. Screenshots are in `ui/e2e/screenshots`.
