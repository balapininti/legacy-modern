# M3 evidence

CardDemo at the pinned commit, via `CardDemoCorpusIT` and `McpContractIT`:

- 56 jobs, 21 maps with their fields, 5 DDL tables; every member with a parser reaches `parsed`, none `failed` or `pending`.
- Hand-checked from the source (`testdata/hand-checked/carddemo-edges.json`): POSTTRAN STEP15 runs CBTRN02C at line 23 with DALYREJS `(+1)`; TRANBKP expands REPROC with the step provenance in app/proc/REPROC.prc; COSGN0A in COSGN00.bms linked to COSGN00C; transaction CC00 to COSGN00C from the CSD at line 378; `CALL 'CBSTM03B' USING WS-M03B-AREA` flows to LK-M03B-AREA.
- Field trace crosses CALL USING on real CardDemo as well as the fixture: `trace_field` WS-M03B-AREA downstream reaches CBSTM03B's LK-M03B-AREA with op `CALL USING`, and upstream in reverse.
- Dead-code candidates fell from 33 before JCL and CSD links to 1, CBTRN01C. A grep of the entire repository finds that name only in its own file.

Hard cases with fixtures in `StructuredParsersTest`: PROCs with nested symbolics and EXEC overrides, DD overrides, GDG relative generations, recursive and missing PROCs, in-stream PROCs, IF/ELSE, DB2 run through IKJEFT01 SYSTSIN, IMS through DFSRRC00 PARM, column 72 BMS continuation.

Defect found by comparing edge counts between runs: re-parsing a late-classified copybook deleted edges of programs that expanded it. Fixed, with a regression test, and `DSNTIAC` is now pinned by the corpus test.

Decision: hand-written readers instead of ANTLR, ADR 0005.
