# M4 evidence

Real model: `gpt-oss-32k:latest` on the local Ollama. Nothing left this machine. `.cache/ollama.yaml` holds the settings.

| Acceptance | Result | How |
|---|---|---|
| Every rule cites an existing range | Met for accepted rules: every line range is inside its program and its file | `RecordedKnowledgeIT` reads the real source file, independently of the validator |
| Unchanged source reruns for 0 tokens | Met: 4 runs in a row, `llmCalls=0, tokensIn=0, tokensOut=0`, each in a new JVM | `RecordedKnowledgeIT`. It found a real bug: contexts built with `Map.of` hashed differently per JVM, so the cache missed about half the time |
| Halts at budget and resumes | Met | `KnowledgePassIT` |
| Real local run over CardDemo programs, measured | All 44 programs were attempted. Summaries were accepted for 39 of 44 | Run below |

## The real run

The full run has 270 units and took about a minute per unit here. It was still running when this was written, and had completed the programs and part of the copybooks. Figures from replaying what it had answered when the final retrieval evaluation ran: 120 units accepted, 20 rejected after one retry, 167 calls, 2,084,960 tokens in, 765,653 out, at no cost.

Its failures by kind when the program stage ended: `migration_note` 8, `summary` 6, `rule` 3, `dictionary` 1. Half were output that was not a JSON object. Most of the rest cited lines that do not exist, such as 2000-2500 in a program ending at 727.

## What a failure costs

A rejected unit is not cached, so it is asked again on every run. "0 tokens on rerun" therefore holds only when every unit in the run was accepted. In the 10-unit recorded set, with 2 rejected units, a rerun makes 4 calls and no others.

## Not proved

The validator proves that citations exist and are in range. It does not prove that a rule is true: that is what SME review is for. Nobody has reviewed the real model's output for accuracy at scale. This is one local open-weight model, and no hosted provider has been exercised.
